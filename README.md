# 💱 USD to TND Converter

A small web tool by **Raed Ghabi** to convert U.S. Dollars (USD) to Tunisian Dinar (TND).  
It’s a simple project built to practice JavaScript and frontend skills.

## 🧑‍💻 What It Does

- Takes a USD amount as input  
- Converts it to TND using a predefined conversion rate (or prompt)  
- Shows the result instantly — no backend needed  

## 🛠️ Built With

- HTML  
- CSS  
- JavaScript
